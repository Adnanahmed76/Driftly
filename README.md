Driftly is an offline-first task management app built with Flutter. It combines Clean Architecture, the BLoC pattern, and local-first data storage to deliver a task manager that works reliably — with or without an internet connection. Tasks are cached instantly with Hive and synced automatically to Firebase Firestore the moment connectivity returns, so nothing you do ever feels blocked by a bad signal.

Built to demonstrate production-grade Flutter architecture: layered domain/data/presentation separation, optimistic UI updates, reactive state management, and thoughtful offline-first UX patterns.
